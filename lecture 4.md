# Effective Communication: Just Ask, Don’t Ask to Ask
## Overview
Don’t ask to ask just ask means when we are facing any issue or problems in order to make any application using coding. Then we stuck at that point and we think for a long time of we do not get any solution then ask to any senior developers or any experts. We can also ask the solution for our problem in the discords where many peoples are willing to help without any charges. So we usually just ask for the people for the help in a good way like “I am facing an error in mine web project here it is mine code and problem “if someone able to resolve your issue then he will help you. If you ask “Is there any java expert, or python expert, or ML expert” then people will ignore you and won’t help you because you want only an expert to help you but in this way expert will also ignore you. Because sometimes the problem or any issue you are facing the non-expert people can also guide and fix your problems. Because the people on discords servers are there to help if you ignore them they will also ignore. So ask the question like that “Is there anyone who can help ma in order to solve mine XYZ problem “.in this way people will help you.
### Wrong way of Asking for help
*	Is there any java expert or a python for mine help?
### Right way of Asking for help 
*	Is there anyone who can help me? I am trying to fix this problem but I am not able to understand what mistake I am making.

## XY Problem
XY problem means that your actual problem is x but instead of asking the solution about  your X problem you asked about the Y the solution you have in you mind.
*	X = Real and actual problem. 
*	Y = the solution that you are thinking.
### Example
*	X = If your mobile is working slow.
*	Y = you think that the Mobiles RAM is not working.
*	And you asked people for help like that “RAM is not working or how to clear it.”
This is wrong you won’t tell people you actual problem you tell people about you Y which is wrong. Because of this the time is waste. Without telling the actual problem if you ask your Y solution then you won’t get any correct solution and waste the others people times. Always tell about your X actual problem.
